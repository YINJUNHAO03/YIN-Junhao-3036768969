This repository reproduces the main results of

> Card, David, and Alan B. Krueger (1994). "Minimum Wages and Employment: A Case Study of the Fast-Food Industry in New Jersey and Pennsylvania." *American Economic Review*, 84(4), 772–793.

and extends the analysis with an independent, county-level difference-in-differences study using administrative (BLS QCEW) data.

## How to reproduce

### 1. Install requirements

```bash
pip install pandas numpy matplotlib statsmodels
```

### 2. Place the raw data in `data/raw/`

The raw data are **not** stored in this repository. Download them and put them
in `data/raw/` exactly as named below.

| File | Source | Instructions |
|---|---|---|
| `public.csv` | Card & Krueger (1994) store-level survey | Download `njmin.zip` from <https://davidcard.berkeley.edu/data_sets/njmin.zip>. Inside is `public.dat` (410 rows, fixed-width). Convert it to CSV and name it `public.csv` (or use the CSV distributed by the course). |
| `sic_1992_qtrly_by_area.zip` | BLS Quarterly Census of Employment and Wages (QCEW) | Go to <https://www.bls.gov/cew/downloadable-data-files.htm>, under **SIC-Based Data Files (1975–2000)**, download `1992` → `Quarterly` → `By Area` (`sic_1992_qtrly_by_area.zip`). |

### 3. Run the full workflow

```bash
python code/run_all.py
```

This generates:

- `results/tables/table2_chain.csv`, `table2_wave1.csv`, `table2_wave2.csv` — Table 2 (store-type distribution + variable means by state, waves 1 and 2)
- `results/tables/table3_employment.csv` — Table 3 (average FTE employment, DiD)
- `results/tables/table4_regressions.csv` — Table 4 (reduced-form regressions)
- `results/figures/figure1_wage_distribution.png` — Figure 1 (starting-wage distributions)
- `results/tables/extension_did.csv` — extension DiD table
- `results/tables/extension_robustness.csv` — extension robustness checks (alternative control group / window / outcome)
- `results/figures/extension_employment_change.png` — extension figure

No manual modification of data or code is required.

## Key results (for comparison with the paper)

- **Table 3**: NJ wave-1 FTE ≈ 20.44, wave-2 ≈ 21.03; PA wave-1 ≈ 23.33, wave-2 ≈ 21.17; DiD ≈ +2.75 (t ≈ 2.03).
- **Table 4**: NJ dummy ≈ 2.33 (1.19); GAP ≈ 15.65 (6.08) → 14.92 (6.21) with controls → 11.91 (7.39) with region dummies; n = 357.
- **Extension**: county-level DiD on SIC 58 ("Eating and Drinking Places") employment ≈ +0.026 log points (t ≈ 1.30, not significant) — consistent with no adverse employment effect. Robust to an eastern-PA control group, a full-quarter window, and an establishments-based outcome.
